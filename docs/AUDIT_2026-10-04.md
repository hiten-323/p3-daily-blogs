## Round 1

Found and fixed:

1. The day-275 generation test read a file the pipeline overwrites. Frozen as `tests/fixtures/day275_pre_repair.json`.
2. Deleted `.github/workflows/repair_once.yml`.
3. Catalog, prompts, proof points, and fallback copy contradicted the jar facts. Prima is Premium Agglomerate 100% Arabica, not freeze-dried. Ultra Blend is 70% coffee. The variety box is not a zero-chicory product. Removed invented lines (100x purer, hand-selected chicory, small-batch, single-origin style, lab-tested certificate, 70–80% chicory, jitter claims).
4. The statistic scrubber treated one allowed percent as permission for the whole sentence (`100% coffee and 40% chicory`). Every percent token is checked. True jar percents (100% coffee / Arabica / Robusta, 70% coffee, 0% chicory) are kept.
5. Claim verification now reads blog fields and runs product-truth checks.
6. Blog links, title/meta/slug shape, and duplicate slugs are gated. The 14-day avoid list reads saved content files instead of a missing `engine.database`.
7. Graph calls send the token as `Authorization: Bearer`, not `access_token=` in the query string.
8. Growth health no longer restores an Actions cache over git `output/`, and its actions are on current major versions.
9. Creative prune uses the Asia/Kolkata date.
10. `save_content` assigns a `generation_id` when a fallback payload has none, so the generate gate can still see who wrote the file.
11. Default hashtag `#NoCicory` corrected to `#NoChicory`.

## Round 2

Found and fixed on a fresh pass, not only the round-1 diff:

1. `slots.py` used `datetime.utcnow()`. Manual dispatch now uses timezone-aware UTC.
2. `sentence_has_unsupported_statistic` was defined before `_STAT_PATTERNS`. It now sits after that pattern.
3. Run lock, snapshots, day number, the Monday brief, the publish log, and analytics/report dates use `today_ist()`. A UTC `date.today()` on the runner disagrees with the content filename between 00:00 and 05:30 IST.
4. Removed an unused date string in the yesterday-snapshot fallback.
5. Product truth no longer drops a whole sentence because an earlier "not" appeared, and it no longer treats "Ultra Blend is 70% coffee, Bold is 100% coffee" as a false Ultra claim. "Ultra Blend doesn't contain chicory" is flagged. A negated "is not 100% coffee" is not.
6. Default hashtags no longer stamp `#FreezeDriedCoffee` on every asset. The suggestion bank no longer offers single-origin, organic, or healthy-coffee tags.
7. Emergency templates, nurture mail, lead magnets, psychology examples, and the JSON examples inside the prompts no longer say the whole brand is 100% coffee or zero chicory. The 40% filler line is no longer shown as a good hook example. "India's first" / "India's only", the chicory float test, and "same caffeine" were removed. Sample CTAs no longer promise the pack is free.
8. Caption repair appends "70% coffee" when the piece is about Ultra Blend, and names the 100% coffee jars otherwise.
9. Shopify article HTML accepts the plain-text `body` field, escapes it, and still accepts legacy `body_html`. Quality checks run on the normalized piece.
10. A blog with copy and no slug or meta description fails `assess()`.
